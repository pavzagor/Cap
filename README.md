# Transcript sentence grouping: English before/after

This evidence compares the original Transcript component from `2766dc045466734e72c6ec9e4fba6012e2bd00ff` with the sentence-grouping follow-up. Both receive the same WebVTT, generated by Cap's existing formatter from one fresh AssemblyAI response.

- Source: [NASA HEASARC historical video archive](https://heasarc.gsfc.nasa.gov/docs/heasarc/videos/historical.html), [original choose.avi](https://heasarc.gsfc.nasa.gov/Videos/historical/choose.avi).
- Clip: approximately 29 seconds of JFK discussing the Moon program. NASA's clip combines two archival excerpts; AssemblyAI assigns them A/B. These raw labels are preserved, not an assertion that they are different people.
- Transcription: Universal-3.5 Pro with Universal-2 fallback, English, punctuation, formatting, disfluencies and speaker labels enabled. Response ID: `aec0ad46-9ea5-4cb5-a5c2-f1345f94b02d`.
- Result: 72 words, 12 caption fragments before, 3 sentence rows after. All words and outer timestamps are preserved.
- Seek proof: selecting the matching row on either side sets the embedded source video to 12.850 seconds.

## What this verifies

Actual old/new React components, real ASR output, sentence grouping, retained speaker labels and timing, and clicks seeking an embedded HTML video. The screenshot and walkthrough were captured in a browser at 1160 by 1050 pixels.

The comparison uses mocked storage/auth hooks. It is not a deployed Cap share page, does not exercise production storage or authentication, and does not demonstrate a backend edit save. The full local share page could not load because MySQL on 127.0.0.1:3306 was unavailable. No additional server or database was started.

Separate local checks cover original cue IDs when editing, live/translated content, timestamped copying, overlapping cues, pauses, and incomplete sentences. The follow-up's scoped suite passed 86 tests, with Biome and TypeScript validation reported in the PR.
